# DevTrack Project

## How to Run

1. Activate venv
2. Run server:
python manage.py runserver

## Endpoints

### POST /api/reporters/
Creates reporter

### GET /api/reporters/
Gets all reporters

### POST /api/issues/
Creates issue

### GET /api/issues/
Gets all issues

## Design Decision

Used OOP concepts with subclasses:
- CriticalIssue
- LowPriorityIssue
